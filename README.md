# Vimfro

Vimfro is a creative studio for experiential, web, marketing and video work. This repository contains its three-section landing page.

Open `index.html` in a browser; there is no build step. The page uses the local fonts in `fonts/` and loads its images from Higgsfield CloudFront. Add `?rec=1` to the page URL to run scroll-driven animations on a timeline for recording. Reduced-motion preferences show the finished content without animation.

The statistics, partner names and award badge are placeholders to be replaced with real Vimfro details. Contact and booking links open [@vimfro on Instagram](https://instagram.com/vimfro).
